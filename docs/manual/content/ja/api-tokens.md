**APIトークン**を使うと、応募者管理システム、人事ツール、スクリプトなどの他のシステムが、人がサインインしなくても管理 API を通じてこの雇用主の作業を行えます。トークンを閲覧・管理できるのは**オーナー**だけです。

## トークンの作成 {#create}

**トークンを作成**では、名前、ロール、そして**スコープ**を指定します。スコープは、求人やフィードの閲覧や書き込みなど、トークンに許可する操作を表します。トークンがロールとスコープで許可された範囲を超えることはありません。メンバーのスコープでは同僚の招待と削除ができるため、それが目的である場合にのみ付与してください。

**シークレットが表示されるのは一度だけです。** トークンを作成した直後に表示されるので、その場で他のシステムにコピーしてください。再表示はできません。紛失した場合は、トークンを取り消して新しいものを作成してください。

## 有効期限、更新、取り消し {#expiry}

トークンは、インストールで設定された期間（既定では 12 か月）が過ぎると期限切れになります。一覧には各トークンの状態（**有効**、**まもなく期限切れ**、**期限切れ**、**取り消し済み**）と**最終使用**日時が表示されます。何か月も使われていないトークンは、取り消すべき候補です。

- **更新**は、シークレットを変えずに有効期限を延長します。そのため、再デプロイは必要ありません。期限切れのトークンでは、同じボタンが**再有効化**と表示されます。
- **取り消し**は、トークンを直ちに、かつ永続的に停止します。取り消したトークンは更新できません。

トークンでトークンを作成・更新することはできず、雇用主を削除することもできません。

API はスキーマで説明されており、このインストールの `/graphql/schema` で参照できます。
