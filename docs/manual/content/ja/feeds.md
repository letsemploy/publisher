## フィード {#feeds}

**フィード**とは、求人を選んでまとめたもので、1 つの `ojobpub.json` ドキュメントとして公開されます。どの雇用主にも `all` というフィードがあります。パートナーごとに異なる求人を公開するには、**新しいフィード**でフィードを追加します。

フィードのページには次の内容が表示されます。

- 最初に、**このフィードを公開しているパーマリンク**と、コピー用の URL
- フィードに含まれる求人と、雇用主のそれ以外の求人が左右に並び、それぞれ検索して求人を追加・削除できます
- フィード内の各求人について、**公開中**かどうか、そうでなければその理由（下書き、無効、期限切れ、不完全）。追加した求人がドキュメントに含まれるのは、公開中である間だけです
- 配信されるとおりのドキュメントの**プレビュー**と、oJobPub スキーマに対して有効かどうかを示すバッジ

フィード自体の URL は、控えめに **テスト** として表示されます。これはフィードの動作確認用です。他者にはパーマリンクを渡してください。開けるのは、サインインした雇用主のメンバーだけです。それ以外の人には存在しないものとして扱われます。

フィードの名前やスラッグを変更しても問題ありません。古いリンクは引き続き機能し、転送されます。フィードを削除すると、その URL は「見つかりません」と応答するようになります。求人は削除されません。

## ドメイン {#permalinks}

求人サイトは、**ご自身のドメイン**の `https://example.com/.well-known/ojobpub.json` で求人を探します。その設定はサイドバーの**ドメイン**で行います。各ドメインには**パーマリンク**があります。背後のフィードを変更しても変わらない URL です。ウェブサイトがそのアドレスでこれを提供し、その後は公開する内容をご自身で切り替えられます。

どの雇用主も、`all` フィードを公開する、まだドメインのないパーマリンクを 1 つ持った状態で始まります。サインイン後の最初のページでは、ドメインが入力されるまでそれを尋ねます。ダッシュボードは、ウェブサイトがそれを提供していることを確認が見つけるまで、お知らせを表示します。

一覧には、ドメインごとに前回の確認結果と**設定を確認**ボタン、**切り替え**ボタン付きのフィードの選択欄、パーマリンクの URL が表示されます。*フィードなし* を選ぶと、URL は維持したまま求人を公開しなくなります。URL を失わずに公開を一時停止する方法です。利用者側に切り替えが反映されるのは、キャッシュされたコピーの有効期限が切れた後です。

**新しいドメイン**では、まずドメインを入力します。`example.com` のようなドメインそのもので、`www.` などのサブドメインは使えません。雇用主のウェブサイトのドメインが候補として表示されます。次にフィード（最初は `all`）、必要に応じて名前と説明を入力します。名前を空欄にするとドメインが名前になります。各ドメインは雇用主ごとに 1 回だけ使えます。

保存すると、編集ページに手順が番号付きで表示されます。ドメイン、Apache・nginx・Caddy 向けにそのまま使える**ウェブサーバーの設定**、そして確認です。

- **リダイレクト**は設定が簡単ですが、リダイレクトをたどらない利用者は失敗します。
- **リバースプロキシ**は、ご自身のドメインから直接文書を提供します。

**設定を確認**は、ウェブサイト上のそのアドレスが実際に何を返すかを問い合わせます。このパーマリンク、そこへのリダイレクト、別のフィード、ファイルのコピー、サイト自身のページ、または何もなし。それぞれの結果に、次にすべきことが示されます。

ドメインを削除すると、そのパーマリンクの URL は *見つかりません* と応答します。URL を残したまま公開を止めたい場合は、代わりに *フィードなし* に切り替えてください。
