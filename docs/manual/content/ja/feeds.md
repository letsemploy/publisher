## フィード {#feeds}

**フィード**とは、求人を選んでまとめたもので、1 つの `ojobpub.json` ドキュメントとして公開されます。どの雇用主にも `all` というフィードがあります。パートナーごとに異なる求人を公開するには、**新しいフィード**でフィードを追加します。

フィードのページには次の内容が表示されます。

- 最初に、**このフィードを公開しているパーマリンク**と、コピー用の URL
- フィードに含まれる求人と、雇用主のそれ以外の求人が左右に並び、それぞれ検索して求人を追加・削除できます
- フィード内の各求人について、**公開中**かどうか、そうでなければその理由（下書き、無効、期限切れ、不完全）。追加した求人がドキュメントに含まれるのは、公開中である間だけです
- 配信されるとおりのドキュメントの**プレビュー**と、oJobPub スキーマに対して有効かどうかを示すバッジ

フィード自体の URL は、控えめに **テスト** として表示されます。これはフィードの動作確認用です。他者にはパーマリンクを渡してください。

フィードの名前やスラッグを変更しても問題ありません。古いリンクは引き続き機能し、転送されます。フィードを削除すると、その URL は「見つかりません」と応答するようになります。求人は削除されません。

## パーマリンク {#permalinks}

**パーマリンク**とは、背後のフィードを変更しても変わらない URL です。ウェブサイトやパートナーの取り込み設定に一度登録すれば、その後は公開する内容をご自身で切り替えられます。

パーマリンクは**フィード**ページの、フィードの下に一覧表示されます。各行にはフィードの選択欄と**切り替え**ボタンがあります。*フィードなし* を選ぶと、URL は維持したまま求人を公開しなくなります。URL を失わずに公開を一時停止する方法です。利用者側に切り替えが反映されるのは、キャッシュされたコピーの有効期限が切れた後です。

**新しいパーマリンク**では、名前、説明、フィードを入力します。作成後、その編集ページには Apache、nginx、Caddy 向けにそのまま使える **ウェブサーバーの設定** が表示され、ご自身のドメインの `/.well-known/ojobpub.json` でもフィードを見つけられるようにできます。

- **リダイレクト**は設定が簡単ですが、リダイレクトに従わない利用者は取得に失敗します
- **リバースプロキシ**は、ご自身のドメインからドキュメントを直接配信します

パーマリンクには **ご自身のウェブサイト** のドメインを入力します。`www.` などのサブドメインを付けず、`example.com` のようにドメインそのものを入力してください。パーマリンクを作成するときは、雇用主のウェブサイトのドメインが候補として表示されます。編集ページには、ウェブサイト上の完全なアドレスと **設定を確認** が表示されます。設定を確認すると、そのアドレスが実際に何を提供しているかを問い合わせます。このパーマリンク、パーマリンクへのリダイレクト、別のフィード、ファイルのコピー、サイト自体のページ、または何もない、のいずれかです。それぞれの結果に、次に行うべきことが示されます。フィードページでは、各パーマリンクがウェブサイトで設定済みかどうかを確認できます。

パーマリンクを削除すると、その URL は「見つかりません」と応答するようになります。URL を残したまま公開を停止するには、代わりに *フィードなし* に切り替えてください。
