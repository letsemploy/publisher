**設定**はユーザーメニューにあります。ここで選んだ内容はアカウントに保存されるため、どの端末でも同じ設定が使われます。設定は種類ごとのセクションに分かれ、左側に一覧表示されます。各セクションは、そのセクションの内容だけを保存します。

- **プロフィール** — **画像**、名前、メールアドレス。5 MB までの JPEG、PNG、GIF を選ぶと、すぐにアップロードされます。画像は正方形に切り抜かれ、撮影場所などのメタデータを除いて保存されます。画像がない場合はイニシャル、または ID プロバイダーが提供する画像で表示されます。
- **表示** — 画面とご自身宛てのメールの**言語**、**テーマ**（システム、ライト、ダーク）、表示されるすべての日時に使う**タイムゾーン**。
- **通知** — **招待メール**（既定でオン）。オフにしても招待は**招待**に届き、メールで通知されないだけです。**週間サマリー**（既定でオフ。*ダッシュボードとアクティビティ* を参照）。

## アカウント {#account}

名前とメールアドレスは ID プロバイダーから取得され、サインインのたびに更新されます。メールアドレスとパスワードのアカウントでは、**プロフィール**で名前を、**パスワード**でパスワードを変更できます。パスワードを変更すると、他のセッションはサインアウトされます。

一覧の最下部に分けて置かれている**アカウントの削除**では、アカウントを削除します。ご自身だけがオーナーである雇用主は一緒に削除されます（ページに事前に表示されます）。他の方と共有している雇用主からは、脱退するだけです。確認のため、メールアドレスを入力します。インストールの唯一の管理者は、自分のアカウントを削除できません。
