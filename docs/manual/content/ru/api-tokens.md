**API-токен** позволяет другой системе — системе управления кандидатами, HR-инструменту, скрипту —
работать с этим работодателем через API управления без входа человека. Видят токены и управляют ими
только **владельцы**.

## Создание токена {#create}

**Создать токен** запрашивает название, роль и набор **областей доступа**, которые определяют, что
токену разрешено, например читать или изменять вакансии или фиды. Токен никогда не получает больше, чем
позволяют его роль и области доступа. Область доступа для людей позволяет приглашать и удалять коллег;
давайте её, только если именно это и нужно.

**Секрет показывается один раз**, сразу после создания токена. Тогда же скопируйте его в другую
систему; показать его снова нельзя. Если он потерян, отзовите токен и создайте новый.

## Срок действия, продление и отзыв {#expiry}

Токен истекает через срок, заданный в установке, по умолчанию через двенадцать месяцев. В списке
показано состояние каждого токена — **активен**, **скоро истекает**, **истёк** или **отозван** — и
**последнее использование**: токен, которым никто не пользовался несколько месяцев, стоит отозвать.

- **Продлить** переносит дату истечения вперёд, не меняя секрет, так что ничего не нужно заново
  развёртывать. У истёкшего токена та же кнопка называется **Возобновить**.
- **Отозвать** останавливает токен сразу и навсегда: отозванный токен продлить нельзя.

Токен не может создавать или продлевать токены, а также удалять работодателя.

API описан своей схемой по адресу `/graphql/schema` в этой установке.
