## Фиды {#feeds}

**Фид** — это подборка ваших вакансий, публикуемая как один документ `ojobpub.json`. У каждого
работодателя есть фид под названием `all`; создайте другие кнопкой **Новый фид**, чтобы публиковать
разные подборки для разных партнёров.

На странице фида показаны:

- в первую очередь **постоянные ссылки, публикующие его**, с их URL для копирования;
- вакансии в фиде и остальные вакансии работодателя рядом друг с другом, у каждого списка свой поиск,
  чтобы добавлять или убирать вакансии;
- для каждой вакансии в фиде — **опубликована** ли она, а если нет, то почему: черновик, неактивна,
  истекла или неполная. Добавленная вакансия есть в документе, только пока она опубликована;
- **предпросмотр** документа точно в том виде, в каком он отдаётся, со значком, показывающим, корректен
  ли он по схеме oJobPub.

Собственный URL фида предлагается неброско, как **Проверить**: он нужен, чтобы опробовать фид. Другим
передавайте вместо него постоянную ссылку. Открыть его могут только участники вашего работодателя, войдя в систему; для всех остальных его не существует.

Переименовать фид или изменить его slug безопасно: старые ссылки продолжают работать и
перенаправляются. После удаления фида его URL отвечает *не найдено*; вакансии не удаляются.

## Домены {#permalinks}

Доски вакансий ищут ваши вакансии на **вашем собственном домене**, по адресу
`https://example.com/.well-known/ojobpub.json`. Настраивается это в разделе **Домены** на боковой
панели. У каждого домена есть **постоянная ссылка**: URL, который остаётся прежним, пока вы меняете фид
за ним. Ваш сайт отдаёт её по этому адресу; дальше вы сами переключаете, что она публикует.

Каждый работодатель начинает с одной постоянной ссылки, которая публикует его фид `all`, пока без
домена. После входа первая страница спрашивает этот домен, пока он не указан, а панель напоминает о
нём, пока проверка не обнаружит, что ваш сайт его отдаёт.

Список показывает для каждого домена, что нашла последняя проверка, с кнопкой **Проверить настройку**,
список ваших фидов с кнопкой **Переключить** и URL постоянной ссылки. Вариант *Нет фида* сохраняет URL,
но не публикует ни одной вакансии — так можно сделать паузу, не теряя URL. Потребители увидят
переключение, когда истечёт срок их кешированной копии.

**Новый домен** сначала спрашивает домен — сам домен, например `example.com`, без `www.` и других
поддоменов; предлагается домен сайта вашего работодателя, — затем фид, для начала `all`, и при желании
название и описание. Пустое название — это домен. Каждый домен используется у работодателя один раз.

После сохранения страница редактирования нумерует шаги: домен, готовая **конфигурация веб-сервера** для
Apache, nginx и Caddy и проверка.

- **перенаправление** настроить проще, но потребитель, который не следует перенаправлениям, ничего не
  получит;
- **обратный прокси** отдаёт документ прямо с вашего домена.

**Проверить настройку** спрашивает адрес на вашем сайте, что он на самом деле отдаёт: эту постоянную
ссылку, перенаправление на неё, другой фид, копию файла, собственную страницу сайта или ничего. Каждый
ответ подсказывает, что делать дальше.

После удаления домена URL его постоянной ссылки отвечает *не найдено*. Чтобы перестать публиковать, но
сохранить URL, переключите его на *Нет фида*.
