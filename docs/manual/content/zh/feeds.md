## 订阅源 {#feeds}

**订阅源**是您职位的一个选集，以一个 `ojobpub.json` 文档的形式发布。每个雇主都有一个名为 `all` 的订阅源；使用**新建订阅源**可以创建更多订阅源，向不同的合作伙伴发布不同的选集。

订阅源页面显示：

- 最上方是**发布此订阅源的永久链接**，附带可复制的 URL；
- 订阅源中的职位与雇主的其余职位并排显示，各带一个搜索框，用于添加或移除职位；
- 对于订阅源中的每个职位，显示它是否**已发布**，如果没有，则说明原因：草稿、已停用、已过期或不完整。您添加的职位只有在已发布时才会出现在文档中；
- 文档的**预览**，与实际提供的内容完全一致，并带有一个标记，说明它是否符合 oJobPub schema。

订阅源自身的 URL 以不显眼的**测试**提供：它用于试用订阅源。请将永久链接提供给他人。只有已登录的雇主成员才能打开它；对其他人而言，它并不存在。

没有带域名的永久链接发布的订阅源不在任何网站上：在您网站上查找职位的招聘平台找不到这些职位。此时其页面会以警告开头，订阅源列表和仪表板会将其标记为**无域名**。请在**域名**中让您的某个域名指向它。

重命名订阅源或更改其 slug 是安全的：旧链接仍然有效并会被转发。删除订阅源后，其 URL 会返回*未找到*；其中的职位不会被删除。

## 域名 {#permalinks}

招聘平台会在**您自己的域名**下的 `https://example.com/.well-known/ojobpub.json` 查找您的职位。您在侧边栏的**域名**中完成设置。每个域名都有一个**永久链接**：一个固定不变的 URL，而您可以更换它背后的订阅源。您的网站在该地址提供它；之后由您自己切换它发布的内容。

每个雇主一开始都有一个永久链接，发布其 `all` 订阅源，但尚无域名。登录后，第一个页面会询问该域名，直到填写为止；仪表板会一直提醒您，直到检查发现您的网站已提供它。

列表为每个域名显示上次检查的结果和**检查设置**按钮、带**切换**按钮的订阅源选择框，以及永久链接的 URL。选择*无订阅源*会保留该 URL，但不发布任何职位——这是在不丢失 URL 的情况下暂停发布的方法。使用方在其缓存副本过期后会看到切换后的内容。

**新建域名**首先要求填写域名——域名本身，例如 `example.com`，不带 `www.` 或其他子域名；系统会提供您雇主网站的域名——然后是订阅源（初始为 `all`），以及可选的名称和描述。名称留空则使用域名。每个域名在一个雇主下只能使用一次。

保存后，编辑页面会按编号列出步骤：域名、适用于 Apache、nginx 和 Caddy 的现成 **Web 服务器配置**，以及检查。

- **重定向**设置更简单，但不跟随重定向的使用方会失败；
- **反向代理**直接从您的域名提供该文档。

**检查设置**会询问您网站上的该地址实际提供什么：此永久链接、指向它的重定向、其他订阅源、文件副本、您网站自己的页面，或什么都没有。每种结果都会说明下一步该做什么。

删除域名后，其永久链接的 URL 会返回*未找到*。如果想停止发布但保留 URL，请改为切换到*无订阅源*。
