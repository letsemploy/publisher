## 仪表板 {#dashboard}

**仪表板**涵盖您当前处理的雇主：

- 已发布、草稿、已过期和已停用职位的**状态统计**，每项都链接到相应筛选后的列表；
- 最近 30 天的**职位链接点击量**，与之前 30 天相比，按天和按国家/地区显示，以及点击最多的职位；
- **需要关注**：14 天内截止的已发布职位、无法发布的已激活职位，以及 30 天无人改动的草稿；
- 最新的**活动**、您的**订阅源**和您的**永久链接**及其 URL。

## 活动 {#activity}

**活动**是雇主的日志：谁在什么时候做了什么，最新的在前。所有者可以看到全部内容；编辑者可以看到除邀请和 API 令牌以外的所有内容，这两项属于所有者的事务。用户菜单中的**我的活动**是您自己的日志：您做过的事，以及发生在您身上的事，例如被邀请或被暂停。

## 每周摘要 {#summary}

在**设置**中开启每周摘要，即可每周收到一封邮件，内容涉及您所属的雇主：各项统计、点击量、新发布和已停用的职位、日期范围已结束的职位、需要关注的事项，以及（对于所有者）即将过期的令牌。没有动态的一周不会发送任何内容。
