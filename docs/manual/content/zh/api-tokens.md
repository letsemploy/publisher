**API 令牌**让其他系统——申请人跟踪系统、HR 工具、脚本——通过管理 API 处理此雇主的事务，无需有人登录。只有**所有者**能看到和管理令牌。

## 创建令牌 {#create}

**创建令牌**会要求填写名称、角色和一组**权限范围**，权限范围规定令牌可以做什么，例如读取或写入职位或订阅源。令牌获得的权限永远不会超出其角色和权限范围所允许的。人员相关的权限范围允许邀请和移除同事；只有确有需要时才授予它。

**密钥只显示一次**，即在创建令牌之后立即显示。请当时就将其复制到另一个系统中；它无法再次显示。如果密钥丢失，请吊销该令牌并创建一个新令牌。

## 过期、续期和吊销 {#expiry}

令牌在安装所设定的期限后过期，默认为十二个月。列表会显示每个令牌的状态——**有效**、**即将过期**、**已过期**或**已吊销**——以及**最后使用**时间：几个月都没人用过的令牌，就是该吊销的那个。

- **续期**会将过期日期向后推，而不更改密钥，因此无需重新部署任何东西。对于已过期的令牌，同一个按钮显示为**重新激活**。
- **吊销**会立即且永久地停用令牌：已吊销的令牌无法续期。

令牌不能创建或续期令牌，也不能删除雇主。

API 由其 schema 记录说明，位于本安装的 `/graphql/schema`。
